## Reporting a Vulnerability

Security and data integrity are taken seriously. If you discover a security vulnerability or credential exposure within the TURBINE-X 2.0 codebase, please follow these guidelines:

1. **Do not disclose the issue publicly** in GitHub Issues, pull requests, or public discussions.
2. Report the vulnerability privately via GitHub's Private Vulnerability Reporting mechanism on the repository:
   `https://github.com/tanishaaaaa9/TURBINE-X-2.0/security/advisories/new`
3. Include:
   - Type of vulnerability.
   - Specific files, paths, or commits affected.
   - Step-by-step reproduction instructions.
   - Potential impact.
4. You will receive an initial response and acknowledgment within 48 hours.
